# Licensing and original wording

Text is CC-BY-4.0 and code is Apache-2.0. All prose is written in original wording from primary sources; no man-page, vendor-doc or kernel `Documentation/` text is copied, and vendor error catalogs are paraphrased per cited code and linked, never reproduced as full tables.

CC-BY-SA was rejected because its share-alike clause conflicts with GPL-2.0 kernel documentation and burdens internal support teams. A public-domain dedication was rejected because attribution is how readers trace claims back to sources.
